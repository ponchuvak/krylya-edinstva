# Крылья единства

Интерактивный музей-квиз об авиации СССР в годы Великой Отечественной войны.

Проект подготовили: Шипов Артём, Подманкова Дарья, Исхаков Антон (10 класс).
Руководитель: Разина Дарья Николаевна.

Пять залов музея, квиз из 10 вопросов, сертификат и страница памяти.

Открыть: https://ponchuvak.github.io/krylya-edinstva/
